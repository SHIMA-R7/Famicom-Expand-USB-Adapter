ファミコン実機と同じダックハント方式で判定します。光線銃に位置を測る機能はないため、 撃った瞬間に画面を走査して「どの的を狙っていたか」を光で判別します。

  1. トリガーを引くと画面が全黒になる(不正防止のチェック)
  2. 的が1つずつ順番に白く光る
  3. センサーが光を検知した瞬間の的が命中

Picoをザッパーモード(GP6のスイッチ)にしてから開始してください。 画面の明るさは上げ、部屋は暗めにすると検知しやすくなります。

Trigger — 左クリック id 72 / DA15 4番ピン
Sensor — 右クリック id 73 / DA15 5番ピン
ランプはゲーム外でも常時反応するので、配線チェックだけにも使えます。 命中しない場合は「点灯時間」を長くすると検知しやすくなります(USB HID経由のぶん実機より遅延があるため、 実機の1フレーム=16.6msでは間に合いません)。黒画面中にセンサーが反応する場合は、 周囲の照明を拾っているかzapper_mode以外の信号が来ています。
